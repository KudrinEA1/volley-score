# Счёт волейбола для трансляции ВКонтакте

Автоматический счёт волейбольного матча в прямой трансляции ВК. Нужны только телефоны, без ноутбуков.

- **Телефон B** стоит на штативе у бумажного перекидного табло. На нём открыта главная страница сервера: она снимает табло камерой и отправляет кадры на сервер.
- **Сервер** (Python) распознаёт цифры через OpenCV, свою маленькую нейросеть `digit_model.npz` и запасной путь через Tesseract. Он ведёт логику матча: партии, питстоп «Уточнить счёт», статистику розыгрышей, смену сторон.
- **Плашка со счётом** (`plashka.html`) лежит на GitHub Pages в репозитории [KudrinEA1/plashka](https://github.com/KudrinEA1/plashka). Её показывает приложение Moblin на **телефоне A**, который ведёт трансляцию.
- **Пульт** `/control` открывается с любого телефона.

Актуальная сборка: **12**.

## Адреса сервера

| Адрес | Назначение |
|---|---|
| `GET /` | страница телефона B: камера на табло |
| `GET /control` | пульт |
| `GET /overlay` | копия плашки, берёт счёт с этого же сервера |
| `GET /score` | счёт в формате JSON, его читает плашка |
| `GET /stats`, `/stats.json` | статистика матча |
| `GET /version` | номер сборки, например `{"build": 12}` |
| `GET /latest.jpg` | последний кадр |
| `GET /frames.zip?key=КЛЮЧ` | архив кадров для дообучения (ключ задан в переменной `FRAMES_KEY`) |
| `POST /frame` | кадр JPEG до 5 МБ, около 1–2 в секунду во время матча |
| `POST /undo`, `/adjust`, `/reset`, `/pit/...`, `/match/...` и др. | команды пульта |

## Файлы

| Файл | Что это |
|---|---|
| `server.py` | веб-сервер (стандартная библиотека Python, порт из переменной `PORT`, по умолчанию 8000) |
| `score.py` | логика матча: счёт, партии, питстоп, статистика, стороны |
| `recognizer.py` | поиск табло на кадре и распознавание |
| `digits.py` | распознавание отдельных цифр нейросетью |
| `digit_model.npz` | обученная нейросеть цифр |
| `digit_model_b64.py` | текстовая копия нейросети (запасная) |
| `train_digits.py` | дообучение нейросети по архиву кадров |
| `index.html` | страница телефона B и пульт `/control` |
| `overlay.html` | плашка на сервере, `SCORE_URL = '/score'` |
| `plashka.html` | плашка для GitHub Pages, `SCORE_URL` = полный адрес сервера + `/score` |
| `stats.html` | страница статистики |
| `requirements.txt` | библиотеки Python |

Сервер хранит состояние в папке `data/` рядом с `server.py`: счёт, статистику, кадры `frames/`, архив матчей `matches/`. Эта папка не загружается в GitHub.

## Требования

- Python 3.11 или новее.
- `opencv-python-headless<5`: в OpenCV 5.0 нет `cv2.HOGDescriptor`, с ним сервер падает.
- Системная программа `tesseract-ocr` (для `pytesseract`).

Запуск на своём компьютере:

```
pip install -r requirements.txt
python server.py
```

Затем откройте http://localhost:8000/version.

## Как вносить изменения

1. Пользователь говорит, что поменять.
2. Claude показывает список правок и ждёт «да».
3. После «да» Claude:
   - правит код;
   - увеличивает номер сборки **в двух местах одинаково**: `BUILD` в `server.py` и `const BUILD` в `index.html`;
   - проверяет на своём компьютере: `python -m py_compile *.py`, при возможности запускает сервер и открывает `/version`;
   - сохраняет изменения (commit) и отправляет их в GitHub (push). Хостинг обновляется сам.
4. Если менялась плашка, Claude отправляет `plashka.html` и в репозиторий `KudrinEA1/plashka`. Там `SCORE_URL` указывает на новый сервер, а в `overlay.html` остаётся `'/score'`.
5. В каждом ответе с изменениями указывается «Актуальная сборка: N».
